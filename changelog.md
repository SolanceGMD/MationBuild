# Changelog

## v0.2.0
- Replace tiny symbol clusters with layered panel-frame presets built from native decorative lines, glows, circles, triangles, and rectangles.
- Add rotation-aware decoration placement and update the portable sample pack.
- Expand the safe import allowlist to known decorative-only object IDs; gameplay objects and triggers remain blocked.
- Keep access-key verification and the undo-friendly editor paste workflow.
- Native Antiprime AutoBuild file compatibility is not claimed without a verified sample/export format.

## v0.1.0
- Add key-verified editor auto-decoration with Tech, Minimal, and Geometric presets.
- Add validated portable `mationbuild-json` v1 import for Geometry Dash 2.2081.
- Add sample template, community catalog/submission portal, and server-side key/template API.
- Add Windows Geode build workflow and CI checks.
